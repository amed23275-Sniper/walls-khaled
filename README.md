# Arabic Walls

تطبيق أندرويد لتطبيق الخلفيات على **شاشة القفل فقط** دون تغيير خلفية الشاشة الرئيسية.

- **صورك أنت:** زر «إضافة صوري من المعرض» يتيح اختيار عدة صور دفعة واحدة؛ تُحفظ داخل التطبيق وتظهر أولاً في الشبكة. اضغط مطولاً على صورة لحذفها من التطبيق (لا تُحذف من معرض الهاتف).
- **12 خلفية عربية** جاهزة (خط عربي + زخرفة إسلامية) تُرسم برمجياً بدقة شاشة جهازك.
- الصور تُقصّ تلقائياً من الأطراف لتملأ الشاشة دون تشويه.
- لا يحتاج التطبيق إلى إنترنت. يتطلب أندرويد 8.0 فأعلى.

## بناء ملف APK

### الطريقة 1: GitHub (بدون تثبيت أي شيء)
1. أنشئ مستودعاً جديداً على GitHub وارفع محتوى هذا المجلد إليه.
2. افتح تبويب **Actions** ثم **Build APK** ثم **Run workflow**.
3. بعد دقائق حمّل `ArabicWalls-debug-apk` من قسم Artifacts، وفيه `app-debug.apk`.

### الطريقة 2: Android Studio
افتح المجلد في Android Studio، انتظر مزامنة Gradle، ثم من القائمة:
**Build ← Build Bundle(s) / APK(s) ← Build APK(s)**.

### الطريقة 3: سطر الأوامر
مع JDK 17 وAndroid SDK وGradle 8.9:

```
gradle assembleDebug
```

الملف الناتج: `app/build/outputs/apk/debug/app-debug.apk`

## ملاحظة
بعض أجهزة الشركات (مثل Xiaomi وHuawei) تتجاهل طلب «شاشة القفل فقط» وتطبّق الخلفية على الشاشتين. إن حدث ذلك فهو من قيود النظام على ذلك الجهاز.
